# Warehouse Picking Optimization

## 프로젝트 소개

건동홍 학술교류제 출품 프로젝트입니다. 대주제는 **"AX 시대의 산업공학"** 이며, 실제 신발 제조 창고의 주문 피킹 데이터를 바탕으로 피킹 경로와 작업 배분을 분석하고 개선하는 방법을 다룹니다.

## 시뮬레이터 (`index.html`)

브라우저에서 바로 열어 쓰는 **피킹 경로 시뮬레이터**입니다(CC-08 출발점 기준). 별도 설치 없이 `index.html`을 열면 됩니다.

- **작업자별 시뮬레이션**: 작업자와 웨이브를 골라 실제 피킹 경로를 재생하고, 작업자별·등급별 결과를 비교합니다.
- **최적 경로 탐색**: 들를 위치를 고르면 방문 순서를 최적화한 경로를 찾아 보여 줍니다(경로 개선에 2-opt 사용). 걷는 속도와 인건비를 입력하면 시간과 비용도 계산합니다.
- **신규 주문 분배**: 신규 주문 파일을 올리면 작업자에게 나누고 경로까지 정합니다. 결과는 엑셀로 저장할 수 있습니다.
- **XAI 설명**: 어떤 웨이브가 왜 더 길었는지, 어떤 웨이브가 왜 비효율적인지 근거를 보여 줍니다.

## 데이터 출처

`data/` 폴더의 데이터는 다음 논문의 공개 데이터셋입니다.

> de Assis et al. (2025). *Order Picking Dataset from a Warehouse of a Footwear Manufacturing Company.* Data in Brief, 61, 111837.

실제 신발 제조 창고의 WMS에서 추출한 자료로, 창고 레이아웃(CAD·PDF·SVG), 상품·보관 위치, 보관 전략별(Random, Class-Based, Dedicated, Hybrid) 배치, 피킹 웨이브, 내비게이션 지점 데이터를 담고 있습니다. 자세한 설명은 [DATASET_DESCRIPTION.md](DATASET_DESCRIPTION.md)를 참고하세요.
